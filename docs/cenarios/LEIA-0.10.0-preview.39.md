# After Rain 0.10.0-preview.39

Instale `After-Rain-0.10.0-preview.39-Setup-Windows-x64.exe` no Windows 10/11 x64.
A alternativa sem instalação é `After-Rain-0.10.0-preview.39-Windows-x64.exe`.
Feche o jogo anterior antes de atualizar. As partidas continuam na mesma pasta.

A tecla C abre a fabricação sem bancada. A bancada de trabalho e a nova bancada de
construção abrem as receitas delas. A cerca agora é feita direto com madeira.

Partidas anteriores continuam compatíveis.
