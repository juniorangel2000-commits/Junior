# After Rain 0.10.0-preview.40

Instale `After-Rain-0.10.0-preview.40-Setup-Windows-x64.exe` no Windows 10/11 x64.
A alternativa sem instalação é `After-Rain-0.10.0-preview.40-Windows-x64.exe`.
Feche o jogo anterior antes de atualizar. As partidas continuam na mesma pasta.

Com o cavalo domado, aperte V perto dele para montar; Shift galopa. Colheitas bem cuidadas
podem sair boas ou excelentes.

Partidas anteriores continuam compatíveis.
