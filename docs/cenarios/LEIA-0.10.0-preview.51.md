# After Rain 0.10.0-preview.51

Instale `After-Rain-0.10.0-preview.51-Setup-Windows-x64.exe` no Windows 10/11 x64.
A alternativa sem instalação é `After-Rain-0.10.0-preview.51-Windows-x64.exe`.
Feche o jogo anterior antes de atualizar. As partidas continuam na mesma pasta.

Capítulo novo de missões, "Terra nova", com a enxada e os primeiros canteiros abertos pelo jogador.
A passagem fechada até a vila ficou sem cercas: só o bloqueio e a dica do Damião.

Correção: o painel de missões não fica mais vazio quando o HUD é recriado.
