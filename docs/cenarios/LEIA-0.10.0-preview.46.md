# After Rain 0.10.0-preview.46

Instale `After-Rain-0.10.0-preview.46-Setup-Windows-x64.exe` no Windows 10/11 x64.
A alternativa sem instalação é `After-Rain-0.10.0-preview.46-Windows-x64.exe`.
Feche o jogo anterior antes de atualizar. As partidas continuam na mesma pasta.

O vale inteiro: Pântano, Ruínas, Estação Ferroviária, Costa das Marés e Pomar Abandonado,
com o rio contínuo do Platô até o mar, moradores trabalhando nos cenários novos e bichos
em cada um deles.
