# After Rain 0.10.0-preview.52 — Almanaque do Vale e painel de Companheiros

**Almanaque do Vale**

- O guia para jogadores agora fica no projeto, em `docs/wiki/almanaque.html`. Ele cobre horta, pratos, máquinas, fabricação, pesca, vila, obras, criação, festas, cenários, mina, expedições, companheiros, e as missões com as conquistas.
- As tabelas saem direto dos dados do jogo, inclusive os 47 capítulos e 269 missões. Para gerar de novo, use `npm run almanaque`.
- A seção de Fabricação explica as telas novas:
  - lista e detalhe;
  - busca;
  - filtro por ícones;
  - fabricar várias (×1, ×5 e Máximo).

**Interface**

- O painel rápido de Companheiros não encosta mais nas barras de vida e vigor: ele fica à esquerda delas, em qualquer altura de tela.

Partidas anteriores continuam compatíveis.
