# After Rain 0.9.7 — mapas finalizados e passagens automáticas

Executável portátil para **Windows 11 x64**. Baixe `After-Rain-0.9.7-Windows-x64.exe` e abra o arquivo.

- Mapas finalizados da Propriedade Abandonada e da Floresta Antiga, com as pinturas, objetos, entradas e saídas enviados pelo autor.
- Troca de cenário automática ao ultrapassar a placa na direção da seta, apenas na passagem marcada. Não é necessário apertar E; a chegada não provoca retorno automático.
- Placas de madeira com setas, sem nomes, e pontes acabadas com cabeceiras de pedra, corrimãos, travessas e ferragens. Entrada nas pontes continua apenas pelas cabeceiras.
- Botão Gráficos na barra superior: iluminação das fases do dia, intensidade, sombras solares, luzes das janelas e restauração do padrão. Preferências salvas para todos os cenários.
- Nova arte de teclado/mouse e painel de controles organizado por atividade, com teclas desenhadas e rolagem para janelas menores.
- Editor de mapas restrito ao desenvolvimento. O executável normal não oferece o botão de edição nem o atalho F2.
- Preservação do progresso e das edições locais ao atualizar os mapas. Transporte e entrega de animais pela corda continuam funcionando nas novas passagens.

**Controles:** WASD/setas para andar; E para interagir; I para inventário; C para fabricar; B para construir; M para mapa; G para soltar a corda; H para personalizar dentro da casa; Ctrl + Alt para tela cheia; roda do mouse ou +/− para zoom; Esc para pausar.

O salvamento usa o mesmo local das versões anteriores. Feche o jogo anterior antes de abrir esta versão.

Validação: TypeScript, 487 testes, build e navegador; executável gerado no Windows pelo GitHub Actions.
