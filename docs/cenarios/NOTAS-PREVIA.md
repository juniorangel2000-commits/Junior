# After Rain 0.9.1 — Natureza renovada

Novas árvores frondosas, pinheiros, pedras com musgo, troncos, samambaias, flores e cogumelos seguindo a referência da Floresta Antiga. Trilhas e chão texturizados. Dimensões do mapa, colisões e progresso preservados.

Baixe `After-Rain-0.9.1-Windows-x64.exe` e execute no Windows 11 x64.

Validação: 322 testes, TypeScript, build e teste no Chromium de transições, mapa, movimento, pausa, acolhimento dos dez animais e salvamento sem reaparecimento. O executável é gerado no Windows pelo GitHub Actions; não foi testado interativamente em Windows neste ambiente.
