# After Rain 0.10.0-preview.49

Instale `After-Rain-0.10.0-preview.49-Setup-Windows-x64.exe` no Windows 10/11 x64.
A alternativa sem instalação é `After-Rain-0.10.0-preview.49-Windows-x64.exe`.
Feche o jogo anterior antes de atualizar. As partidas continuam na mesma pasta.

Missões em capítulos: 46 capítulos e 266 missões guiam o jogo inteiro, do primeiro canteiro até o
metal negro. Cada capítulo concluído dá uma conquista, com aviso, som e uma medalha saindo do
personagem. A última conquista é "O Vale Renasceu".
As telas de fabricar foram refeitas, com lista, busca e fabricar várias de uma vez.
