# After Rain 0.10.0-preview.38

Instale `After-Rain-0.10.0-preview.38-Setup-Windows-x64.exe` no Windows 10/11 x64.
A alternativa sem instalação é `After-Rain-0.10.0-preview.38-Windows-x64.exe`.
Feche o jogo anterior antes de atualizar. As partidas continuam na mesma pasta.

Corrige a tela preta ao voltar da Floresta Antiga para a Propriedade. Os patos da
Floresta escondem os pés na água, passeiam pela margem e fogem sem travar.

Partidas anteriores continuam compatíveis.
