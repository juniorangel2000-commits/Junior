## Restaurar

Para recuperar uma captura específica, use a referência histórica e o caminho do manifesto:

```bash
git restore --source=v0.10.0-preview.31 -- "docs/cenarios/alto-da-serra/Mina-decorada.png"
```

Também há um ZIP integral, fora do repositório, no workspace desta manutenção: `/workspace/after-rain-archives/previas-ate-preview31.zip`. O arquivo foi verificado por SHA-256 e sua restauração integral foi testada. Para restaurar o ZIP para uma pasta separada:

```bash
python3 scripts/archive-historical-previews.py --backup /caminho/previas-ate-preview31.zip --restore-to /caminho/restauracao
```

O script recusa sobrescrever arquivos existentes. Sem `--apply`, executa somente a conferência do manifesto. Uma aplicação exige um ZIP completo verificado fora do repositório, e recusa arquivos que tenham mudado desde a revisão.
