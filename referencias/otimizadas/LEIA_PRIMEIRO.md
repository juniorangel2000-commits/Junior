## Como usar no Codex

1. Extraia este ZIP para uma pasta do projeto.
2. Comece por webp/mapas/mapa_expandido.webp e pelas imagens de webp/construcoes/. Anexe as imagens individualmente quando quiser discutir sua aparência.
3. Se o campo de anexo não aceitar WebP, use a versão correspondente em png/. Envie em pequenos grupos se necessário.
4. Para trabalhar com arquivos locais, informe ao Codex o caminho da pasta extraída e peça para ler indice.csv. O ZIP serve para transporte; extraia-o para acessar as imagens.
5. Use PNG no projeto quando precisar desse formato. As versões WebP também são sem perdas. Não amplie ou reduza com suavização ao trabalhar com pixel art.

A documentação e os ativos individuais do jogo continuam no pacote original. Este pacote reúne referências e prévias; o inventário JSON registra todas as imagens encontradas, inclusive nos ZIPs internos. Duplicatas visuais foram incluídas uma vez e mapeadas em duplicatas.json.
